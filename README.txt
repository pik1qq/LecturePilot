LECTURE PILOT by pik1 — 1.8 (тестовая версия)

НОВОЕ
- Светлая и серая тёмная темы: переключатель в шапке панели; тема сохраняется
  локально и применяется также к окну управления. Реальный Windows UI не проверен.
- Проверка обновлений из github.com/pik1qq/LecturePilot и ручное подтверждение
  установки. Подпись манифеста и хэш EXE проверяются встроенным открытым ключом.
  Во время занятия кнопка установки недоступна. Обновление и сборка пока НЕ
  испытаны на реальном Windows; не раздавай без проверки. При ошибке открой
  старую программу или резервный LecturePilot-previous.exe.
- Автоконспект, бот и платежи в этой версии не реализованы.
- В архиве исходники и Windows-сборщик, а НЕ готовый EXE.

В ZIP НЕТ ГОТОВОГО EXE: здесь исходники и автоматический сборщик для Windows.
Сборка EXE, показ окна на панели задач и ярлыки требуют проверки на Windows.

КАК ОБНОВИТЬ
1. В старой версии нажми «Завершить всё» / «Завершить приложение».
2. Распакуй ВЕСЬ новый ZIP в новую постоянную папку, не запускай из архива.
3. На компьютере для СБОРКИ нужен Python 3.10+ x64 с python.org, с компонентом
   Tcl/Tk (обычно включён при стандартной установке). Запусти build_exe.bat.
   Для первой сборки нужен интернет. Не устанавливай tkinter через pip.
4. При успехе откроется dist с LecturePilot.exe. Запусти НОВЫЙ EXE.
5. Друзьям передавай только проверенный LecturePilot.exe. Python им не нужен,
   но должен быть установлен совместимый Chrome, Edge или Яндекс Браузер.
6. Не передавай папку %LOCALAPPDATA%\LecturePilot: там профиль и cookies.
7. Не отключай антивирус/защиту Windows. EXE не подписан сертификатом.
   Если сборка не удалась, пришли ПЕРВУЮ ошибку из окна сборки.

ОКНО ПРИЛОЖЕНИЯ И ПАНЕЛЬ ЗАДАЧ
- На Windows добавлено небольшое обычное окно «Lecture Pilot by pik1» со своей
  иконкой. Оно должно отображаться на панели задач (не значок в трее).
- Ровно две кнопки:
  «Открыть панель» — открывает или возвращает страницу с расписанием.
  «Завершить всё» — после подтверждения выключает приложение и закрывает
  управляемые окна панели и лекции. Обычный браузер и его вкладки не закрываются.
- Крестик НАТИВНОГО окна также предлагает «Завершить всё».
- Сворачивание окна не прекращает работу. Можно оставить компьютер работать.
- НОВОЕ ПОВЕДЕНИЕ: закрытие СТРАНИЦЫ в браузере больше НЕ завершает программу.
  Это заменяет режим 1.5 с выходом после закрытия последней вкладки.
- При обычном ручном запуске также запрашивается открытие панели. При входе
  в Windows окно управления сворачивается; сохранённый автовход работает без
  открытия страницы панели. Не путай кнопку «Открыть панель» с разрешением
  автовхода: первое согласие по-прежнему даётся на странице расписания.
- Повторный запуск EXE просит уже работающую копию открыть панель и вернуть
  окно управления. Второй экземпляр расписания не создаётся.
- Закрепление на панели задач: правый клик по работающей иконке → закрепить.
  Программа не закрепляет себя принудительно и не меняет панель задач.
- При длительном завершении дождись закрытия управляемого браузера. Программа
  не делает taskkill всех chrome.exe и не вмешивается в личный браузер.

РАБОЧИЙ СТОЛ И ПОИСК «ПУСК»
- В веб-панели в блоке «После перезагрузки» нажми «Создать ярлыки».
- Создаются ярлыки «Lecture Pilot by pik1» на рабочем столе и в меню «Пуск»
  только текущего пользователя. Учитывается перенаправление Desktop в OneDrive.
- Это не копия EXE: ярлыки ссылаются на текущий файл. Сохрани EXE в постоянной
  папке. После переноса создай ярлыки заново.
- Поиск Windows может показать новый пункт не сразу, в зависимости от индекса.
- В шапке, названии вкладки, подвале панели, окне и свойствах EXE — by pik1.

БРАУЗЕР И БЕЗОПАСНОЕ ЗАКРЫТИЕ
- Панель открывается в отдельном управляемом профиле, а не в твоих личных
  вкладках. Это позволяет кнопке «Завершить всё» закрывать и панель тоже.
- Для локальной панели используется выбранный совместимый браузер. Если
  системный браузер не поддержан, только ПАНЕЛЬ может открыться в установленном
  Edge, Chrome или Яндекс. Настройка браузера ЛЕКЦИЙ от этого не меняется.
- Лекции также в изолированном профиле. Firefox и неизвестные браузеры для
  автоматического входа не поддержаны; выбери совместимый браузер явно.
- Все дополнительные вкладки, открытые ВНУТРИ управляемых профилей программы,
  тоже закроются при «Завершить всё». Для личных дел используй обычный браузер.
- Программа не закрывает вручную открытые копии панели в личном браузере.
  Если открыть адрес панели самостоятельно в обычном браузере, после выхода
  эта вкладка может остаться с сообщением о потере связи. Для управляемой панели
  используй кнопку приложения.
- «Пауза» в расписании закрывает только лекцию и оставляет панель и приложение.

НАСТРОЙКА И АВТОЗАПУСК
1. Введи группу (поиск от двух символов) и СВОИ фамилию/имя. Выбери полный номер
   группы, браузер, ранний вход 0–5 минут и занятия. Сохрани настройки.
2. Включи «Запоминать автовход», один раз запусти расписание и подтверди согласие.
   После изменения имени/группы согласие нужно заново. После обычного перезапуска — нет.
3. Нажми «Включить / исправить автозапуск» в блоке «После перезагрузки».
4. Проверь отдельно запуск с Windows и сохранённый автовход.
5. Если запись отключена Windows, включи LecturePilot в Параметры → Приложения →
   Автозагрузка. Приложение НЕ обходит StartupApproved или ограничения системы.
6. Запуск происходит при ВХОДЕ в ту же учётную запись Windows. Он не включает
   компьютер и не обходит экран входа. Компьютер не должен спать.
- Используется явно разрешённая запись текущего пользователя HKCU\Software\
  Microsoft\Windows\CurrentVersion\Run. Проверяется чтением; админ-права не нужны.
- Держи EXE в постоянной папке. После перемещения исправь автозапуск.
- «Пауза» и «Завершить всё» не стирают запоминание или согласие. Чтобы отключить
  восстановление, поставь паузу, сними «Запоминать автовход» и СОХРАНИ настройки.
- «Убрать из автозагрузки» удаляет запись Windows, не завершает текущую работу.
- Настройки атомарно сохраняются с резервной копией в %LOCALAPPDATA%\LecturePilot.
- После запуска сначала нужно свежее расписание. Если интернет не готов —
  повтор загрузки через 15 секунд. Если браузер временно не готов, ожидание не
  сбрасывается. При успехе расписание обновляется раз в 5 минут.
- При ошибке пришли снимок статусов и последние строки истории. Локальный журнал:
  %LOCALAPPDATA%\LecturePilot\startup-events.jsonl. Перед отправкой проверь его.
  Не присылай cookies, runtime.json, профиль браузера или HAR.

РАСПИСАНИЕ И ОГРАНИЧЕНИЯ
- Основной источник — mosrasp.ru; если он не отвечает или не содержит данные,
  используется rasp.dmami.ru. При восстановлении mosrasp приложение вернётся
  к нему. Подсказки и проверка группы также работают с резервным источником.
- Группа передаётся источнику. Поддерживаются группы, опубликованные источниками,
  включая группы с вечерним временем и сессией; не только 000-000.
- Источник показан над расписанием. При смене источника требуется проверить
  галочки и снова нажать «Запустить расписание»: идентификаторы и прежние
  исключения в разных источниках могут не совпадать. Во время активной лекции
  переключение откладывается. Автовход при этом не обещан без подтверждения.
- Если текущая дата вне периода официального расписания, загрузка отклоняется.
  При неполном периоде выводится предупреждение, дальше него входы запрещены.
  Неясное чередование недель или неоднозначные ссылки не выбираются автоматически.
- Ошибка обоих источников сохраняет прежние данные; при устаревании более
  20 минут новые входы приостанавливаются. Проверяй расписание университета.
- Период — сегодня и следующие 13 дней, время Europe/Moscow, обновление 5 минут.
- При отсутствии свежих данных более 20 минут новые входы приостанавливаются.
- Ссылки берутся для каждой пары отдельно. Без опубликованной однозначной ссылки
  автоматического выбора нет. СДО, онлайн-курсы и очные занятия не открываются.
- Одна активная лекция. Пересечения и подгруппы исключай галочками вручную.
- Окно лекции закрывается в КОНЦЕ ПО РАСПИСАНИЮ, даже если преподаватель ещё
  говорит. Далее ожидается следующая выбранная пара.
- Имя и явные кнопки входа заполняются автоматически, но успех не гарантируется
  при изменениях сайта. Пароли, CAPTCHA, подтверждения присутствия — вручную.
- Экспериментальный фокус НЕ гарантирует активность у организатора. Отправленные
  клиентом isFocused/isSoundEnabled/isVideoEnabled не доказывают статус сервера.
- Звук выключается только на странице лекции через HTML media и Web Audio gain.
  Это НЕ штатная кнопка браузера «Отключить звук вкладки». На живом МТС Линк
  способ не проверен и может влиять на индикатор звука/внимания.
- Имя передаётся МТС Линк, группа — источникам расписания. Для удаления данных сначала выключи
  автозапуск и программу, затем удали %LOCALAPPDATA%\LecturePilot.

ОДИН EXE
Ресурсы и драйвер Playwright упаковываются в one-file EXE. Он временно распакует
свои ресурсы при запуске. Настройки и профили всё равно хранятся в пользовательской
папке. Браузер в EXE не входит. Это НЕ отсутствие любых файлов на диске.
Иконка и сведения «by pik1» встраиваются при новой сборке. Замена ICO рядом со
старым EXE его не меняет. Если закреплён старый ярлык, открепи и закрепи новый.

ПРОВЕРКИ
Автоматически проверяются расписание, сохранение/восстановление автовхода,
пауза, настройки браузеров, звук локальных страниц, контракт двух кнопок,
генерация команд ярлыков и закрытие только управляемых контекстов браузера.
Окно Tk, реальная панель задач, поиск «Пуск», ярлыки и сборка EXE НЕ испытаны
на настоящей Windows. На Linux нет Tk GUI для визуальной проверки нативного окна.
Лекции при проверках не посещаются. Используются локальные страницы и имитации.

ЗАПУСК ИСХОДНИКОВ
start.bat требует Windows Python с Tcl/Tk. Для друзей собирай EXE; сам архив
исходников не является готовой программой для запуска одним двойным кликом.
