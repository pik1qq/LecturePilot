# Lecture Pilot by pik1

Приложение для Windows с расписанием и управляемым входом на вебинары. Экспериментальный проект: перед применением проверь актуальность расписания и фактический вход на занятие.

## Пользователям

- Скачайте `LecturePilot.exe` из раздела **Releases**, когда опубликована версия.
- Сохраните EXE в постоянной папке, запустите и настройте профиль. Для обновления файл должен называться `LecturePilot.exe`.
- Светлая и тёмная темы выбираются в шапке и сохраняются на компьютере; окно приложения тоже меняет оформление.
- Расписание берётся с mosrasp.ru, при недоступности — с rasp.dmami.ru. При переключении источника проверьте выбор занятий и повторно включите автовход.
- При новом выпуске программа может проверить подпись, скачать EXE и предложить перезапуск. Активную лекцию обновление не прерывает. Экспериментальную функцию обновления следует испытать на Windows до распространения.
- Автоконспект и оплата в этой версии **не реализованы**.

## Разработчику

Подробности сборки и ограничения — в `README.txt`. Для сборки EXE нужен Windows и Python 3.10+ с Tcl/Tk: `build_exe.bat`.

В репозиторий нельзя добавлять настройки, профили браузера, cookies, ключи API и закрытый ключ подписи. Открытый ключ проверки в `update_public_key.txt` не является секретом.

Выпуск: добавьте закрытый ключ подписи в GitHub Actions secret `LECTUREPILOT_SIGNING_KEY`, убедитесь, что версия во всех файлах изменена, и вручную запустите workflow **Build signed Windows release** на ветке main с той же версией, что в `updater.py`. Workflow соберёт EXE, подпишет манифест и создаст черновик релиза. Он не станет доступен пользователям, пока вы не проверите сборку на Windows и не опубликуете его вручную. Проверяйте сборку и обновление на Windows до раздачи; при потере ключа старые клиенты не смогут доверять новому ключу автоматически.
